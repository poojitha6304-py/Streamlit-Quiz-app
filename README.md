# Streamlit Quiz App

An interactive web-based online quiz portal built using Python and Streamlit.

## 🚀 Features
- **User Authentication:** Enter a Roll Number to begin the quiz.
- **Subject Selection:** Choose between multiple subjects like Python, English, and Maths.
- **Dynamic Scoring:** Keeps track of your quiz scores.

## 🛠️ Setup and Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd Streamlit-Quiz-app
   ```

2. **Install required dependencies:**
   ```bash
   pip install streamlit
   ```

3. **Run the application:**
   ```bash
   streamlit run Quiz.py
   ```
